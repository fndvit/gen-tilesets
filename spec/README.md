# Specification

**Authoritative:** `02`–`08`. These constrain code. A disagreement between one of
these and anything else means the other thing is wrong.

**Index, not authority:** `00`, `01`. Useful for finding things. Every known-false
statement in this package was in a document that summarised another document, and
these are the two that remain. Verify against the cited section before relying on
a claim either one makes about `02`–`08`.

**`09` is authoritative for the editor**, except where it reproduces a table or a
rule from another document. There, read the other document.

**Section numbers are append-only** (`01` §11.4). Nothing is renumbered; a removed
section keeps its number as a tombstone.
