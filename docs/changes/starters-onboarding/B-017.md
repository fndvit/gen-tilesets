## What changed
A new user is shown how a tileset is made, on an example, and can leave at any time.
- **The first visit opens Collage and runs the tour** over it. Later visits open what was kept, or an empty tileset. If Collage fails to load, the editor opens empty with a failure notice, and the tour runs as a replay does.
- **The tour** points at one part of the editor per step, through a cut-out in a dimmed backdrop, with a bubble of text. **9 steps on a first visit:** Welcome, Grid & size, Tiles, Tile group, Operations, An operation (Collage's operation 4, opened, with the picture), Breakpoints, Randomness and Your own tileset. **8 on a replay**, without An operation. Next always works, and the user doesn't have to do the step.
- **Skip tour** on every step but the last, **Esc** on every step, and **Done** on the last all end it. Ending it by any way is remembered.
- **"?"** in the top bar, after Undo, replays the tour over whatever is open. A replay never changes the file or an open draft.
- **Undo is icon-only at 40rem and below**, so "?" fits in the top bar.
- The seen flag is in `localStorage` (`gen-tilesets.editor.tourSeen`). When storage is blocked, the tour still shows, and it shows again on the next visit.
