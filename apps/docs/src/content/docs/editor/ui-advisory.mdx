## Overview

Some advisories are about one control: two tile groups with the same name (spec `09` §12.2's
sixth), a palette reordered under a random Source (eighth), rotation ends that are the same angle
(ninth). Each is shown as a muted line with an info icon, right under that control, where the
author can act on it.

It has no box, no colour and no ✕, and it goes away when its condition does. It never looks like
an error (**E16**).

## In detail

### Public surface

| Prop | Type | Meaning |
| --- | --- | --- |
| `when` | `boolean` | The condition. |
| `children` | `Snippet` | The line. |

### Inputs → outputs

- `when` is copied into `shown` by an effect, but only while `entry.active` is false. So the line
  never appears or goes while the author is typing or dragging, only once the value is committed
  (Pol, W1).
- A `role="status"` wrapper is always in the DOM, so the line is announced when it appears. It is
  hidden while empty, so it takes no gap in a grid.
