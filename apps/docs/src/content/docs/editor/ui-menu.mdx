## Overview

An icon button (the `more` icon) that opens a list of actions under it. It holds the actions
a row needs but should not show at rest. In iteration 2 it is an operation card's Move earlier,
Move later and Delete (and since Stage 2, a palette entry's Change tile, Move earlier, Move later
and Remove): the card then reads as what the operation does, not as the things that
can be done to it.

## In detail

### Public surface

| Prop | Type | Notes |
|---|---|---|
| `label` | `string` | The button's accessible name, also the list's. |
| `items` | `MenuItem[]` | `{ label, icon, onSelect, disabled? }`, in order. |
| `align` | `"left" \| "right"` | Default `"right"`. Which edge of the anchor the list lines up with. |
| `anchor` | `HTMLElement` | What the list is placed against. Defaults to the trigger. |
| `trigger` | `Snippet<[MenuTrigger]>` | A button of the caller's own in place of the ⋯ icon button. It gets `{ open, toggle, attach }`: `{@attach attach}` on the button, `toggle` on its click, `open` for `aria-expanded`. |

### Behaviour

- It follows the WAI-ARIA menu button pattern: `aria-haspopup="menu"` and `aria-expanded` on
  the button, `role="menu"` and `role="menuitem"` in the list.
- Opening focuses the first enabled item. The arrow keys, Home and End move between enabled
  items, and Enter or Space runs one. Escape closes and returns focus to the button. Tab, or a
  pointer press outside, closes.
- After an action, focus returns to the button once the DOM has settled. A move reinserts the
  row, which would otherwise drop focus. After a delete the button is gone.
- The list is `position: fixed`, measured from the anchor, so the scrolling sidebar never clips
  it. It opens upward when there is too little room below. The placement and the outside-press
  test are [`popover.ts`](/editor/ui-popover-ts/)'s `placeAt` and `pressedOutside`, shared with
  the tile picker and the Explainer.
- A row's ⋯ menu right-aligns with its button. A [Split button](/editor/ui-split-button/)
  passes its chevron as `trigger`, its whole control as `anchor` and `align="left"`: the list
  opens under the control and lines up with its left edge, while Escape and the refocus after an
  action still go to the chevron. The trigger is a snippet rather than an exported `show`/`close`
  so that opening, closing and refocusing stay in `Menu`.
